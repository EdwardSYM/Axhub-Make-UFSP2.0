# 案例库功能菜单组件规格

## 1. 组件定位

本组件是“案例库（AI改造）（甘肃）”模块的唯一左侧功能菜单，供案例检索、一般案例管理、案例聚类分析、典型案例管理、案例采集管理和案例标签管理页面共同复用。

## 2. 菜单结构

- 案例检索。
- 一般案例管理。
- 案例聚类分析。
- 典型案例管理：申请、审核。
- 案例采集管理。
- 案例标签管理。

## 3. 交互与路由

- 菜单支持 `272px` 展开态和 `64px` 收起态。
- 典型案例管理支持二级展开和收起，默认展开。
- 案例检索进入独立原型 `/prototypes/gansu-case-search`。
- 其他功能进入 `/prototypes/case-library-ai?feature=<feature_key>`。
- 当前页面通过 `activeKey` 统一表达选中状态，各业务页面不得复制或维护自己的菜单清单。

## 4. 视觉基线

组件继续使用案例库已确认的 `case-sidebar`、`case-nav` 系列样式：菜单行高 `44px`、展开宽度 `272px`、收起宽度 `64px`、低饱和蓝灰选中态和克制的图标反馈，不新增独立视觉变体。
