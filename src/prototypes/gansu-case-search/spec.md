# 甘肃案例检索原型规格

## 1. 页面定位

本原型是“案例库（AI改造）（甘肃）→ 智能检索 → 案例智能检索”页面，用于甘肃一般案例的智能检索、结果筛选和详情查阅。页面内容代码和样式与湖南案例检索相互隔离，左侧功能菜单统一复用 `src/components/case-library-feature-menu`，与甘肃案例库其他页面共用一套菜单结构、折叠行为和路由。

本期以甘肃一般案例现行标准字段为唯一数据口径，使用本地 mock 数据展示，不接入真实接口、数据库、权限、全文检索或 AI 模型。

## 2. 功能范围

### 2.1 检索首页

- 默认检索范围为已入库的一般案例，不把未入库、审核中数据混入检索结果。
- 主检索覆盖案例编号、案例标题、案例描述、涉及主体、案例标签及自然语言问题描述。
- 首页展示检索示例、最近检索和当前可检索范围；范围按案例数量、发生时间和五类来源类型表达，不沿用“文书范围”口径。
- 检索说明通过推荐词末尾的轻量信息图标按需展开。

### 2.2 检索结果

- 结果页采用“单一命令栏 + 左侧筛选 + 连续结果册”结构，保留筛选面板收起、展开和重置演示。
- 常驻筛选项为：来源类型、所属地区、发生时间、案例标签、涉及主体。
- 更多筛选项为：案例编号、录入机构以及来源类型联动条件。
- 来源类型联动规则：
  - 日常监督形成、专项监督形成：筛选关联问题。
  - 上级下发：筛选下发文件。
  - 外部公开案例：筛选发布机构或来源网站，并可选择发布时间。
  - 其他来源：筛选来源名称。
- 结果摘要展示案例标题、案例编号、来源类型、所属地区、发生时间、涉及主体、案例标签、字段级命中内容、相关度和可解释匹配原因。
- 排序演示仅保留相关度优先、发生时间最新、发生时间最早。
- 每条结果支持展开单条深度分析，分析依据来自案例标题、案例描述、案例标签和来源信息，不模拟文书正文分析。

### 2.3 案例详情

- 详情页由案例摘要、检索问题和“命中内容 / 案例详情 / 来源材料”三部分组成。
- 命中内容按案例标题、案例描述、案例标签或来源信息等实际命中字段定位。
- 案例信息展示：案例编号、入库状态、来源类型、所属地区、发生时间、涉及主体、录入机构、录入人。
- 案例内容展示案例描述、备注和案例标签。
- 来源材料按来源类型展示对应来源字段，不默认假设存在文号、OA 正文或源文书：
  - 日常监督形成、专项监督形成：关联问题。
  - 上级下发：下发单位、文件名称、文件编号。
  - 外部公开案例：发布机构或来源网站、原文链接、发布时间、来源说明。
  - 其他来源：来源名称、来源说明。
- 材料附件和典型案例关联按数据是否存在展示列表或空状态；仅外部公开案例存在原文链接时显示“查看原文”。
- 右侧保留匹配原因、相似案例和继续检索入口。

## 3. 信息架构

```text
甘肃案例智能检索
├── 公共 TopBar
├── 公共案例库功能菜单
│   ├── 智能检索
│   │   ├── 案例智能检索（当前）
│   │   └── 反哺建议检索
│   ├── 一般案例管理
│   ├── 案例聚类分析
│   ├── 典型案例管理 / 申请、审核
│   ├── 案例采集管理
│   └── 案例标签管理
└── 检索展示区
    └── 检索首页 → 检索结果 → 案例详情
```

其他菜单项通过公共菜单进入甘肃案例库对应页面。后续甘肃个性化调整不得复制菜单或反向影响湖南案例检索。

## 4. 数据与交互

- 数据全部为页面内甘肃一般案例本地 mock 数据，其中首条案例按用户提供的现行标准字段示例整理。
- 筛选、排序、面板收展、条件重置、结果详情、深度分析和反馈均使用页面本地状态模拟。
- 来源信息由 `sourceType` 与对应 `sourceFields` 联动展示；缺失附件、典型案例关联或原文链接时展示明确空状态，不虚构入口。
- 左侧功能菜单由公共组件统一维护，当前页面固定选中“案例智能检索”。
- Axure 变量暴露当前 `feature_key` 和 `feature_name`。

## 5. 布局与视觉

- 复用公共 `TopBar` 和案例库功能菜单，不重新实现公共导航。
- 保持现有财会监督 V2.0 蓝灰视觉体系、弱边界、紧凑信息密度和 `4px / 8px` 圆角层级。
- 首页突出单一检索任务；结果页采用双工作区；详情页采用“内容定位 + 标准案例详情 / 来源材料 + 匹配解释”三栏阅读区。
- 结果项使用连续白色结果册和弱分隔，不改为独立悬浮卡片。
- 详情信息通过字段分组、浅底和留白建立层级，不使用文书纸张、正文预览或 OA 来源等不适用于标准案例的数据形态。

## 6. 暂不处理

- 真实案例检索、向量检索、融合排序、相关度计算和 AI 调用。
- 真实来源链接、附件下载、问题关联和典型案例关联接口。
- 数据库、权限、审批、日志、持久化和生产级校验。
- 甘肃案例库其他菜单页面的字段改造。
