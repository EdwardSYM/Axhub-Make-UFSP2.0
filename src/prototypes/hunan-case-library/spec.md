# 湖南案例库演示原型规格

## 1. 页面定位

本原型用于湖南场景的案例库功能演示。在现有列表框架基础上，新增符合湖南一期需求的案例检索主链路，并保留原有入库、档案、分析和典型案例模块作为后续范围参考。不接入真实接口、数据库、权限、文书解析服务或 AI 模型。

页面尽量复用现有 `case-library-ai` 的公共顶栏、左侧功能菜单、业务目录、标准工具栏、表格、分页和抽屉表达方式，并针对湖南需求调整模块名称、页面内容和 mock 数据。

## 2. 功能范围

### 2.1 案例检索

- 作为案例库默认入口，支持输入文号、专有名词、单位名称或自然语言问题描述。
- 检索首页主标题只显示“案例智能检索”，不使用图标和副标题说明。
- 已确认视觉方案：标题使用自然中文排版；主搜索框与搜索按钮采用圆润一体式胶囊结构；检索说明收敛为推荐词末尾的轻量信息图标，通过就近浮层按需展开，不再孤立占据行尾。该方案已沉淀为同类智能检索页的局部基准。
- 结果页采用“单一命令栏 + 连续结果册”结构：返回、检索框、结果数量和排序位于同一行，页面不再设置独立顶部搜索区或重复结果标题区。检索框中的查询内容即当前检索条件，不在页面其他位置重复展示。结果数量通过数字强调表达，排序直接使用“相关度优先 / 最新时间 / 最早时间”选项，不再重复显示“排序”标签。
- 结果页搜索框复用首页检索框的视觉语言，作为紧凑版本使用白色胶囊输入面、蓝色圆润按钮和同源阴影；检索按钮收敛为 `64px` 宽，并与胶囊右边缘保留 `8px` 内间距。命令栏本身保持透明，不再额外套白色底板。筛选和排序下拉框隐藏浏览器原生箭头，使用右侧内缩的统一细线箭头。
- 筛选面板与命令栏统一为 `8px` 圆角并对齐顶线；结果项相关度使用直角分隔信息列，不使用大圆角色块。
- 检索结果使用一张连续白色结果册承载，通过行间弱分隔和统一节奏表达层级，不再把每条结果做成独立悬浮卡片。
- “深度分析”和“查看详情”并入每条结果的标题行右侧，不设置独立操作栏；不单独显示原文预览图标，原文统一从案例详情进入。
- 结果页采用连续滚动浏览，不展示分页控件；结果册在最后一条数据后直接收底，不保留页脚空白，并与左侧筛选面板保持同一内容区底部节奏。
- 结果页主体使用等高白色双工作区：左侧筛选面板和右侧结果册都铺满可用内容高度。数据不足一屏时，剩余空间保持为所属工作区的白色阅读面，不露出大块灰色页面画布；数据超出时仅结果册内部滚动。
- 筛选面板支持收起与展开；收起后保留窄图标栏作为恢复入口，右侧结果区自动扩展占用释放宽度。
- 检索首页展示检索示例、最近检索和当前可检索文书范围，不使用无真实依据的热门排行。
- 检索结果页保留检索框，主检索同时覆盖文号、文书标题、相关单位和自然语言问题描述。
- 左侧常驻筛选与知识库元数据保持对应，提供年度、文书类型、监督领域、违规类型、文号和相关单位。其中监督领域使用约定类别单选，违规类型作为可搜索多选条件。
- “更多筛选”按需展开正式发文日期范围、处理方式和政策依据：处理方式使用可搜索多选，政策依据使用文件名称关键词，避免将高基数字段做成长下拉列表。
- 文书标题由主检索覆盖，不重复设置独立筛选项；年度与发文日期分开表达，不再使用含义模糊的“年度 / 日期”标签。
- 元数据值无法识别时保持为空，不在原型中强制归入“其他”类别。
- 结果页继续提供相关度、时间排序演示。
- 结果默认表达 TopK 相关案例，展示标题、文号、文书类型、日期、相关单位、命中片段、相关度和可解释匹配原因。
- 检索阶段按“Embedding + Hybrid + Rerank”概念返回备选案例；页面中的相关度、命中片段和“检索依据”属于检索层解释，不与生成式分析混用。
- 每条备选案例提供可选“深度分析”操作。触发后在当前结果行内模拟 LLM 生成过程，分析“为什么相似、共同问题、关键差异、是否值得参考”，不跳转页面、不默认对全部结果批量生成。
- 深度分析采用单块嵌入式浅色分析带承载，结论区突出参考价值和建议，并提供可定位的原文分析依据；同一时刻只展开一条结果，避免破坏列表扫描效率。
- 深度分析支持重新生成、有帮助/无帮助评价、负向原因选择、补充意见和提交反馈演示。反馈控件按需展开，不在未操作时占据结果行高度。
- 支持从结果进入案例详情，并在详情页查看正文和源文件。
- 案例详情展示本次检索信息、匹配原因、命中片段定位、正文高亮、源文件附件、OA 来源入口和继续查看相似案例。
- 本期不展示面向全部检索结果的生成式汇总答案；仅对用户主动选择的单条备选案例提供可选深度分析演示。

### 2.2 案例入库管理

- 展示待确认、待补充、不入库和全部状态。
- 支持文书导入、手工补录、批量入库、查询和筛选的静态入口。
- 展示文书解析、数据质量、信息补充和标签确认结果。
- 点击“确认信息”进入全页面入库确认工作区，左右对照原始文书与提取结果。
- 入库确认页展示数据质量检查、案例信息补充、分类标签确认、暂存、不入库和确认入库操作。

### 2.3 案例档案

- 按“年度—检查计划—检查项目”展示归档目录。
- 支持关键词、文号、年度、被检查单位等条件的静态检索入口。
- 展示正式入库案例列表。
- 点击案例进入档案详情页，通过页签查看档案信息、案卷文书和关联分析。
- 关联分析展示相似案例推荐和问题库关联问题，文书列表提供在线预览和下载演示。

### 2.4 案例智能分析

- 展示年度、案例来源和地区筛选。
- 展示案例总量、已分析案例、聚类主题和整改措施模式等概览。
- 通过页签展示聚类分析、整改措施分析和问题画像。
- 点击聚类主题进入分析详情页，展示共性特征、整改措施模式和关联案例样本。
- 支持导出分析报告和形成典型案例候选的静态反馈。

### 2.5 典型案例管理

- 展示候选案例、待发布、已发布和全部状态。
- 展示典型案例标题、类型、来源案例、代表性和当前状态。
- 支持查看、编辑、形成典型案例和发布的静态入口。

## 3. 信息架构

```text
湖南案例库
├── 公共 TopBar
├── 案例库功能菜单
│   ├── 案例检索（默认）
│   ├── 案例入库管理
│   ├── 案例档案
│   ├── 案例智能分析
│   └── 典型案例管理
└── 当前模块展示区
```

“检索首页 → 相似案例结果 → 案例详情”作为案例检索菜单内部的连续流程，不拆分为独立菜单。其他模块内部状态和分析类型使用页面内页签、目录和轻量提示表达，不增加第三层系统菜单。

## 4. 数据与交互

- 数据全部为页面内本地 mock 数据，内容使用湖南省财政监督场景示例。
- 左侧功能菜单支持展开态和收起态，并通过 `feature` 查询参数记录当前模块。
- 工具栏、表格行操作、页签、全页面操作区和抽屉仅提供演示反馈，不执行真实上传、保存、入库、发布或模型计算。
- 检索结果使用本地固定结果模拟混合检索、筛选、排序、相关度和命中解释。
- 元数据筛选项使用本地状态模拟单选、多选、关键词、日期范围、展开收起和条件重置，不执行真实知识库查询。
- 深度分析、重新分析、生成等待和用户反馈均使用页面本地状态与 mock 内容模拟，不调用真实 LLM、反馈接口或数据持久化服务。
- Axure 变量暴露当前 `feature_key` 和 `feature_name`。

## 5. 布局与视觉

- 复用公共 `TopBar`，不得重新实现顶部导航。
- 页面采用“TopBar → 左侧案例库菜单 → 右侧业务区”的标准业务页结构。
- 左侧菜单展开宽度 `272px`、收起宽度 `64px`、行高 `44px`。
- 业务列表使用白色面板、`32px` 控件、`4px` 圆角、蓝灰表头和简版分页。
- 湖南案例库内承担业务容器职责的面板和卡片统一使用 `8px` 圆角，不混用 `6px / 12px / 16px`；输入、选择器、普通按钮等控件使用 `4px`，检索胶囊、圆形返回按钮等明确形态组件按自身语义保留全圆角。
- 关键操作页使用 `64px` 白底页头、圆形返回按钮、集中操作区和分节内容面板。
- 案例检索首页突出单一检索任务；结果页采用“筛选条件 + 结果列表”；详情页采用“内容定位 + 文书阅读 + 匹配解释”的三栏阅读工作区。
- 案例检索详情页使用连续白色业务页面：顶部操作栏、案例摘要和三栏正文在同一阅读面内自然接续，不再拆成多张悬浮卡片；栏间仅用留白和弱分隔线组织，选中项、命中片段、匹配标签和文书纸张保留必要浅底或边界。
- 案例检索详情页的页头只显示“案例详情”，不重复文号和文书类型；案例标题与完整元数据只在摘要区出现。内容定位已表达当前查看范围时，正文区不再重复显示“命中内容 / 文书正文 / 源文件附件”标题栏。分隔线按三级层级使用：摘要与核验阅读区之间使用全宽弱横线表达主阶段切换；三栏之间使用上下留白、末端渐隐的短竖线建立阅读列；右侧两个辅助分组之间使用缩进渐隐短横线。不同层级在线长、方向和透明度上必须有区别，不能全部删除，也不能全部画成贯穿边框。
- 案例检索三页遵循信息层级优先、边界克制：普通分组、摘要、结果项和侧栏先通过留白、浅底和文字层级建立结构，再按业务阶段、阅读列、局部分组和独立载体补充不同权重的边界；不以线条或卡片数量作为独立优化指标。
- 入库确认页采用“原文预览 + 信息核验”双栏工作区；档案详情和分析详情使用概览区、页签或分组内容。
- 分析页面使用轻量指标带、扁平列表和浅色信息分组，不使用营销页式大卡片。

## 6. 暂不处理

- 真实 OA 或其他系统接口。
- 文书解析、OCR、模型训练和智能推荐算法。
- 真实全文检索、向量检索、融合排序、检索准确度计算、LLM 调用和反馈数据闭环。
- 完整审批流、权限流、操作日志和生产级校验。
- 典型案例独立编辑发布页，以及每个模块的全部新增、审核和辅助详情页面。
