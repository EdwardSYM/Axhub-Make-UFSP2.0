# 本级监督分析规格文档

## 1. 页面定位

本页面是全景分析下的“本级监督分析”独立原型，当前阶段只实现“本级监督分析 - 日常监督默认页”。

页面面向领导和管理岗，用于在当前本级范围内识别：

- 哪些部门 / 单位需要关注；
- 哪些日常监督主题需要关注；
- 哪些部门 / 单位在哪些监督主题下出现关注信号；
- 规则触发、预警疑点和疑点核实结果如何支撑上述判断。

本页不使用地图。根据 0601 详细设计方案，本级页面使用综合表现分作为静态原型的关注分层、颜色和排序口径，用于判断部门 / 单位、主题是否进入高关注或中关注；该分值不替代正式评价体系得分，不接真实业务公式。

## 2. 默认口径

| 项目 | 当前口径 |
|---|---|
| 行政区划 | 湖南省本级 |
| 监督分类 | 日常监督 |
| 统计时间 | 本月 / 本期 |
| 监督主题 | 全部日常主题 |
| 分析对象 | 当前本级范围内的部门 / 单位 |
| 中间主展示 | 主题—主体关注矩阵 |

当前实现默认覆盖“多主题 × 多部门 / 单位”和“单部门 / 单位 × 多主题”两类原型状态；部门 / 单位详情页后续单独设计。

## 3. 与全辖监督分析的边界

| 对比项 | 全辖监督分析 | 本级监督分析 |
|---|---|---|
| 分析对象 | 当前行政区划下的本级节点 + 下级区划 | 当前本级范围内的部门 / 单位 |
| 行政区划选项 | 湖南省全辖、市州全辖等全辖节点 | 湖南省本级、市本级、区县本级等本级节点 |
| 中间展示 | 本级主体卡 + 下级区划地图 | 主题—主体关注矩阵 |
| 点击本级 | 跳转到本级监督分析 | 页面内部联动矩阵、主体、主题和底部预警 |

全辖页不提供“本级”作为筛选项；从全辖页点击本级入口时跳转到本页面。

## 4. 页面结构

| 层级 | 区域 | 本级作用 |
|---|---|---|
| 第 0 层 | 顶栏 / 分析口径区 | 明确当前本级节点、监督分类、监督主题和统计时间 |
| 第 1 层 | 概览区 | 概括当前本级日常监督关注情况 |
| 第 2 层左侧 | 需关注部门 / 单位 | 识别哪些部门 / 单位需要关注 |
| 第 2 层中间 | 部门 / 单位关注分布 | 展示主题—主体关注矩阵 |
| 第 2 层右侧 | 需关注主题 | 识别哪些监督主题需要关注 |
| 第 3 层 | 监控预警与明细追溯 | 解释上方关注结果背后的规则触发、预警疑点、确认问题和案例链路 |

核心浏览逻辑：

```text
先看总体概览 -> 看哪些部门 / 单位需要关注 -> 看主题—主体关注矩阵 -> 看哪些主题需要关注 -> 用监控预警与明细追溯解释原因
```

## 5. 顶栏 / 分析口径区

顶栏仍复用全辖监督分析结构，不改造成主体筛选区。

- 标题：本级监督分析。
- 说明：展示当前本级范围内，日常监督下需关注部门 / 单位、需关注主题及监控预警情况。
- 筛选顺序：统计时间、行政区划、监督分类、监督主题和重置，视觉与全辖监督分析保持一致。
- 统计时间：默认本月；选择“自定义”后展开开始日期和结束日期两个自定义日历字段。
- 行政区划：只展示本级节点，例如湖南省本级、长沙市本级、区县本级；下拉保留省 / 市 / 区县本级层级缩进。
- 监督分类：默认日常监督；专项监督作为后续扩展入口。
- 监督主题：默认全部日常主题，日常监督下按业务监控和专题监控分组展示。
- 重置：恢复默认筛选为本月 / 湖南省本级 / 日常监督 / 全部日常主题。
- 当前统计口径：按统计时间、当前本级节点、监督分类、监督主题和数据更新时间展示。

## 6. 概览区

概览区沿用全辖页最新 6 张风险识别类卡片，但本级口径解释为部门 / 单位：

| 卡片 | 本级展示含义 |
|---|---|
| 高关注部门/单位数 | 当前本级范围内综合表现分低于 60 分的部门 / 单位数量 |
| 高关注主题数 | 当前本级范围内综合表现分低于 60 分的日常监督主题数量 |
| 预警疑点数量 | 当前本级范围内规则识别出的疑点线索数量 |
| 确认问题数量 | 当前本级范围内经核实确认的问题数量 |
| 确认问题金额 | 当前本级范围内确认问题涉及金额 |
| 案例沉淀数 | 当前本级范围内已入库、已发布或已审核待发布的案例成果数量 |

选择具体监督主题后，前两张卡片切换为：

| 卡片 | 本级展示含义 |
|---|---|
| 平均分 | 当前主题下本级部门 / 单位评价得分平均值 |
| 低分部门/单位数 | 当前主题下低于阈值或命中关注条件的部门 / 单位数量 |

后四张卡片继续展示预警疑点、确认问题、确认金额和案例沉淀，但统计范围限定为当前主题。

卡片视觉与全辖页一致：

- 顶部卡片只常驻指标名称和主数字，不常驻长说明文字。
- 说明入口使用左下角标准“i”图标，悬停展示说明、口径、补充信息和统计范围。
- 点击卡片打开右侧抽屉，抽屉采用标题、当前口径、主摘要、口径条、摘要指标、筛选项和明细表结构。
- 案例沉淀数是成果指标，不参与综合表现分计算。

## 7. 左侧板块：需关注部门 / 单位

展示对象为部门 / 单位，默认展示高关注和中关注对象。

展示字段：

- 主体名称；
- 关注状态；
- 综合表现分；
- 低分主题数 / 有效主题数；
- 预警疑点数；
- 确认问题数量；
- 确认问题金额；
- 案例沉淀数；
- 关注原因。

默认按高关注优先、综合表现分低优先、确认问题金额大优先、确认问题数量多优先、预警疑点多优先排序。

点击某部门 / 单位后，中间矩阵定位该主体列，并提供“返回本级”入口恢复到当前本级全部部门 / 单位矩阵；底部监控预警与明细追溯保持当前本级口径。

## 8. 中间板块：主题—主体关注矩阵

本级页面不使用地图，中间板块展示“主题—主体关注矩阵”。

标题区参考全辖监督分析最新板块标题规则：主标题靠左，右侧只放简短当前区划 / 已选主体提示，不重复展示对象和矩阵口径。

视觉规则：

- 中间区域内部采用无边框设计，参考抽屉内信息块的浅底、无描边、低阴影层级。
- 矩阵区域不再重复外层标题；矩阵上方仅保留当前展示数量、滚动提示和“返回本级”等必要操作。
- 保持当前中间卡片尺寸，矩阵内容超出时在卡片内部滚动，不撑高页面。
- 矩阵小卡片保持原列宽，不因多单位、多主题或单主体钻取而横向拉伸；中间列和矩阵滚动容器必须限制在板块自身宽度内。
- 默认本级态展示多部门 / 单位、多主题矩阵；点击部门 / 单位后展示单部门 / 单位的多主题矩阵。
- 多部门 / 单位和多主题同时超出时，矩阵容器支持横向和纵向滚动。
- 可点击的主体列头、主题行头、矩阵单元格使用首页小卡片式 hover：轻微底色变化、上移 1px、浅阴影，不增加箭头或额外装饰。

| 维度 | 含义 |
|---|---|
| 行维度 | 日常监督主题 |
| 列维度 | 部门 / 单位 |
| 单元格 | 该部门 / 单位在该主题下的关注状态 |

颜色含义：

| 状态 | 含义 |
|---|---|
| 高关注 | 低分主题、规则预警、疑点或问题金额明显集中 |
| 中关注 | 存在一定低分、预警或异常情况 |
| 低关注 | 当前关注信号较少 |
| 暂无数据 | 当前部门 / 单位在该主题下无可分析数据 |

交互：

- 点击矩阵主体列头：联动左侧需关注部门 / 单位。
- 点击主体列头或左侧部门 / 单位后：矩阵进入单主体多主题视图，标题行显示“返回本级”按钮。
- 点击“返回本级”：清除当前部门 / 单位钻取，回到当前本级全部部门 / 单位矩阵。
- 点击矩阵主题行头：切换监督主题筛选。
- 点击矩阵单元格：锁定主体 + 主题组合，并将底部切换到“明细追溯”页签。

## 9. 右侧板块：需关注主题

右侧用于识别当前本级范围内哪些日常监督主题需要重点关注。

展示字段：

- 主题名称；
- 关注状态；
- 主题综合表现分；
- 主题平均分；
- 中位分；
- 低分部门 / 单位数；
- 预警疑点数量；
- 确认问题数量；
- 确认问题金额；
- 案例沉淀数；
- 关注原因。

默认按综合表现分低优先、确认问题金额大优先、确认问题数量多优先、低分部门 / 单位多优先、预警疑点多优先排序。

选择具体主题后，右侧切换为“指标扣分分析”，展示指标名称、指标得分、低分主体数、关联规则、预警疑点、确认问题和扣分原因。

## 10. 底部板块：监控预警与明细追溯

底部复用全辖页最新五页签结构，但主体口径统一解释为部门 / 单位。

| 页签 | 本级作用 |
|---|---|
| 规则触发分析 | 看当前本级范围内哪些业务类型 / 主题类型的规则触发集中 |
| 预警疑点分析 | 看哪些部门 / 单位、哪些主题疑点集中 |
| 确认问题分析 | 看哪些部门 / 单位确认问题多、金额大及其来源疑点 |
| 案例沉淀分析 | 看哪些部门 / 单位或主题形成案例沉淀 |
| 明细追溯 | 看部门 / 单位、主题、规则、疑点、问题、案例之间的链路 |

## 11. 实现边界

- 当前仅完成前端静态原型、mock 数据和本地状态联动。
- 不接真实接口，不实现真实业务计算，不新增后端、不做权限或复杂校验。
- 当前主要复用全辖监督分析的卡片、三栏、表格、抽屉和浅色财会监督 V2.0 样式。
- 顶部筛选、自定义日期、指标说明、右侧抽屉和底部五页签参考全辖监督分析最新样式。
- 中间板块按本级方案替换为矩阵，不沿用全辖地图。
- 本级中间矩阵使用静态 mock 数据扩展多部门 / 单位、多主题样例，仅用于原型表达，不代表真实业务公式。
