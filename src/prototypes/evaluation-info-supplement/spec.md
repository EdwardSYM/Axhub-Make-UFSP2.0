# 考核信息补充

## 1. 业务与功能

### 1.1 核心目标

本页面用于“考核指标与佐证材料审核”。用户在考核评价指标对应上传佐证材料后，系统根据考核指标要求与佐证材料内容进行一致性、合规性和正确性检查，并给出异常原因与处理建议。

页面只做前端静态演示：使用页面内本地 mock 数据，不接入后台接口、权限、数据库、真实业务公式或真实 AI 能力。

### 1.2 功能清单

- **考核信息补充列表**：参考用户截图中的指标库表格结构，展示年度目录、状态页签、模糊查询、工具栏、指标表格和评分标准。
- **标准业务框架**：复用问题库 AI 改造页面的 `ufsp-*` 框架方向，采用浅蓝业务画布、可收起功能侧栏、白色业务面板、48px 页签、56px 工具栏和 32px 表格行。
- **指标材料上传入口**：行内保留“上传提交”，用于表达每个考核指标补充佐证材料的业务入口。
- **多选校验提交**：用户在列表中直接点击整行选中指标，可多选；再次点击已选中行取消选中，点击“校验提交”后进入全页面智能校验结果页。
- **退回提醒**：仅存在被退回数据时显示右上角悬浮红色提醒，提醒不占据列表行空间，支持短时间自动消失和手动关闭。
- **智能校验结果页**：左侧复用问题库 AI 校验页的快照表结构，展示本次提交指标的勾选状态、指标名称、评分方式、要求佐证、上传时间、材料状态和校验结果；支持全部数据、全部一致、存在异常筛选。
- **一致性/合规性结果**：右侧复用问题库 AI 校验页的结论卡和异常事实分组结构，展示“全部一致 / 存在异常”、异常事实统计、指标要求、佐证附件、判断原因和处理建议。
- **推理过程**：顶部保留“推理过程”入口，右侧抽屉展示指标要求识别、佐证材料解析、一致性比对和合规性判断步骤。

### 1.3 交互要点

- 点击左侧页面内“考核评价”：跳转到 `prototypes/evaluation-assessment`。
- 点击表格行：改变本次校验提交范围；默认选中 3 条异常或待复核指标，选中行使用蓝色整行高亮表达，再次点击取消选中。
- 被退回行：未选中时使用浅红底和红色状态文字；若同时被选中，选中蓝色优先于退回红色。
- 点击“校验提交”：进入全页面智能校验页，左侧只展示本次勾选的指标，不展示未选中指标。
- 点击结果页左侧指标：右侧切换当前指标的校验摘要和异常明细。
- 点击结果页左侧筛选：按“全部数据 / 全部一致 / 存在异常”过滤本次提交指标。
- 点击“推理过程”：打开右侧抽屉查看静态推理步骤。
- 点击“刷新状态 / 提交 / 修改”：当前阶段保留页面级入口样式，不接入真实流程。

## 2. 内容规划

### 2.1 信息架构

```text
考核信息补充
├── 顶部全局导航（复用 TopBar）
├── 左侧考评库功能菜单
│   ├── 考核信息补充
│   └── 考核评价
└── 列表模式
    ├── 页面标题与退回提示
    ├── 状态页签（基本信息 / 待提交 / 已提交）
    ├── 年度目录
    ├── 工具栏（校验提交 / 批量上传 / 导出 / 查询）
    ├── 指标与佐证材料表格
    └── 居中分页
└── 智能校验模式
    ├── 左侧考评库功能菜单
    └── 校验业务面板
        ├── 顶部标题操作栏
        ├── 左侧本次提交指标快照表
        ├── 校验报告摘要
        ├── 当前指标异常明细
        └── 推理过程抽屉
```

### 2.2 数据来源

- **数据类型**：考核指标、评分方式、要求佐证、上传时限、上传时间、材料状态、AI 校验结果和异常说明。
- **数据源**：页面内本地 mock 数据。
- **关键字段**：
  - `name`：三级考核指标名称。
  - `requireEvidence`：是否要求上传佐证。
  - `deadline` / `uploadTime`：上传时限和实际上传时间。
  - `material` / `materialStatus`：佐证材料名称和材料状态。
  - `checkResult`：校验结果，取值为“全部一致 / 存在异常”。
  - `consistency`：一致性结论。
  - `compliance`：合规性结论。
  - `riskReason`：异常原因说明。
  - `requirementText`：考核要求或评分标准。
  - `evidenceText`：佐证材料提取内容。
  - `suggestion`：处理建议。
  - `dataStatus`：静态数据状态说明。

## 3. 布局与结构

- **列表布局**：顶部导航 + 浅蓝业务画布 + 标准功能侧栏 + 右侧白色业务面板；业务面板内部为跨栏状态页签、左侧年度目录和右侧横向滚动指标表格。
- **表格结构**：使用多级表头表达一级指标、二级指标、三级指标、考核要求和评分标准；控件高度保持 32px，表格行高约 34px。
- **校验页布局**：与问题库校验页一致，TopBar 下方先进入浅蓝业务画布；第一列为考评库功能菜单，菜单右侧才是全页面白底校验工作区；校验工作区内左侧约 460px 使用问题库同款快照表展示本次提交指标，右侧展示结论摘要和异常事实明细。
- **桌面优先**：优先保证 1440px 以上宽屏展示；表格字段多时通过横向滚动承接，不压缩关键文本。

## 4. 视觉规范

- 遵循 `/src/docs/业务页面设计规范.md`、问题库 AI 校验页方向和用户截图中的指标库表格密度；按钮、页签、工具栏、分页和校验页头部按问题库 `ufsp-*` 组件标准收敛。
- 使用顶栏同源深蓝 `#2A487E` 与低饱和表头蓝，异常行使用红色整行高亮，贴近截图中退回/异常数据的表达。
- 智能校验页避免堆叠重卡片，使用问题库同款白底结论卡、左侧状态线、浅底异常事实行和字段分组表达层级。
- 左侧本次提交区保留问题库快照表的扫描方式，只展示校验判断所需的少量指标字段，避免把原表所有字段搬入结果页。
