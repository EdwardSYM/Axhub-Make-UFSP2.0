# 监督者工作台 - 规格文档

## 1. 页面定位

`/prototypes/supervisor-workbench` 是“监督者工作台”原型入口。

当前版本按用户要求直接复制 `src/prototypes/topic-workbench2` 的重点领域整改工作台，用于后续在同一界面基础上调整监督者角色视角。

## 2. 适用范围

- 页面先保留重点领域整改工作台的整体结构、样式、交互和本地模拟数据。
- 页面显示名调整为“监督者工作台”，打开入口时不再显示源页面名称。
- 后续调整可围绕监督者的任务督办、审核跟踪、整改研判、综合分析等任务继续细化。

## 3. 页面结构

- 顶部：复用全局导航、页面标题、更新时间和设置入口。
- 主体：复用监督流程、待办事项、资源入口、评价分析、趋势查看和三级指标分析能力。
- 弹层：复用业务全流程视图，支持悬停查看节点说明并点击进入功能页。
- 评价分析：复用重点领域整改工作台的指标树、规则定义、政策依据、智能分析与趋势切换。

## 4. 数据与交互

- 继续使用本目录复制出的 `data.ts`、`style.css` 和 `LocalDebtLevel3Panel.tsx`。
- 继续使用本地 mock 数据，不接入后端接口、数据库或真实权限判断。
- 流程节点、待办标签、图表筛选、评价趋势切换等交互保持与重点领域整改工作台一致。

## 5. 独立维护约束

- 本页面为物理复制出的独立页面，不从 `topic-workbench2` import 或 re-export。
- 后续如需角色化调整，仅修改本目录内相关代码和规格文档。
