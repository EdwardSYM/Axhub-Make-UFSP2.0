# 全辖日常监督分析规格文档

## 1. 页面定位

本页面是全局分析下的“全辖日常监督分析”原型，用于在当前统计范围内汇总日常监督评分、规则触发、异常拦截和处置闭环结果，识别区划、主体和监控主题的风险高低及主要成因。

页面主线为：

```text
区划综合风险 -> 主体综合风险 -> 监控主题评分短板 -> 指标扣分原因 -> 规则/异常数据证据
```

核心判断依据是评分结果，规则触发、异常数据、阻断拦截和处置闭环作为解释评分结果的证据，不再沿用旧版“风险主体、风险主题、风险事项、待办环节事项”等泛风险指标做顶层主线。

## 2. 页面结构

- 顶部系统导航：复用公共 `TopBar`，保留当前系统级导航、搜索、消息和用户区风格。
- 标题说明区：标题为“全辖日常监督分析”，说明文案压缩为“以评分结果识别风险高低，以规则触发和异常数据解释扣分成因。”标题与说明同处一行，右侧展示当前位置、统计维度和数据更新时间。
- 全局筛选区：所有全局筛选保持一行展示，监控分类和监控项使用两级选择控件，不铺开展示全部选项。
- 总览指标区：展示综合得分、高风险主体数、高风险主题数、异常数据数、阻断拦截数、处置闭环率 6 个指标。
- 中部分析区：左侧“监控主题评分态势”、中间“全辖综合风险分布”湖南地图、右侧“主体风险排行”和“评分短板与规则证据”。
- 底部明细区：整行展示“明细追溯”，通过页签承接主体主题评分、指标扣分证据、异常数据、规则拦截流水。

## 3. 筛选设计

### 3.1 第一行全局筛选

- 统计时间：今日、昨日、本月、本季度、本年、自定义。
- 自定义时间范围：仅统计时间选择“自定义”时展示开始日期和结束日期。
- 行政区划：湖南省全辖、省本级、市州、区县等 mock 选项；选择后立即刷新当前页面 mock 口径。
- 重置按钮：恢复本月、湖南省全辖、全部监控分类、全部监控项。
- 重置：位于筛选行最右侧，使用图标按钮；不再保留搜索/查询按钮。
- 数据更新时间：固定 mock 文案 `2026年5月14日 15:00`，只在标题区右侧展示，不在筛选区重复展示。

### 3.2 第二行监控分类

监控分类作为一级选择，仅包含：

- 全部
- 业务监控
- 专题监控

处理方式、预警级别、规则类型、处理状态等细分条件不放顶部，后续放在对应板块或明细页签内。

### 3.3 第三行监控项

- 选择“全部”时，监控项下拉中按“业务监控”和“专题监控”分组展示。
- 选择“业务监控”时，展示基础信息、项目库、预算编制、预算批复、预算调整调剂、指标管理、预算执行、资产管理、会计核算。
- 选择“专题监控”时，展示地方政府债务、高标准农田建设资金使用、行政事业单位国有资产处置、减税降费政策落实、违规返还财政收入、三保、三公、一卡通。
- 点击监控项后，地图、主体排行、评分短板和明细追溯同步切换到该监控项口径。

## 4. 数据口径

### 4.1 基础分析单元

前端 mock 数据以“主体 + 监控主题 + 评分结果”为最小分析单元，字段包括：

- `subjectName`
- `regionName`
- `subjectType`
- `monitorCategory`
- `monitorTheme`
- `themeScore`
- `themeWeight`
- `subjectWeight`
- `riskLevel`
- `lowScoreIndicators`
- `abnormalCount`
- `interceptCount`
- `closedLoopRate`
- `mainDeductionReason`

主体综合得分由该主体下多个监控主题得分按 `themeWeight` 汇总；当前 mock 阶段使用等权，字段预留后续真实权重。区划综合得分由区划内主体综合得分按 `subjectWeight` 汇总；当前 mock 阶段同样使用等权。

### 4.2 风险等级

风险等级只由评分划分，异常数量只作为解释证据：

- 90 分及以上：低风险
- 80-90 分：较低风险
- 70-80 分：中风险
- 60-70 分：较高风险
- 60 分以下：高风险

### 4.3 Mock 数据范围

区划数据覆盖湖南场景：长沙市、株洲市、湘潭市、衡阳市、邵阳市、岳阳市、常德市、张家界市、益阳市、郴州市、永州市、怀化市、娄底市、湘西州、省本级。

主体数据包括长沙市财政局、株洲市财政局、衡阳市财政局、省直预算单位A、省直预算单位B、某区县财政局、某主管部门等。

规则示例包括无预算支付拦截规则、超预算支付预警规则、三保资金保障预警规则、债务风险指标异常规则、资产处置审批完整性规则、预算执行进度异常规则、会计核算科目使用异常规则。

## 5. 总览指标

总览指标保留横向统计卡样式，但内容改为评分结果和规则证据组合：

- 综合得分：当前筛选范围内综合评分结果。
- 高风险主体数：当前范围内风险等级为高风险或较高风险的主体数量。
- 高风险主题数：当前范围内低分或高风险的监控主题数量。
- 异常数据数：当前范围内规则命中的异常业务数据条数。
- 阻断拦截数：当前范围内被规则阻断拦截的事项数量。
- 处置闭环率：当前范围内异常数据或处理单已完成闭环的比例。

卡片在“全局总览2”的指标入口卡质感基础上进一步压缩高度，只常显标题、数值及单位。标题固定在左上角并预留长标题单行省略空间；数值和单位固定在右下角，右对齐展示，长数字从右向左占位并单行省略。卡片内不展示较上期、环比、新增变化、AI 结论常显标签、点击查看文案或额外装饰说明。鼠标悬停通过提示说明可点击。点击指标卡先打开指标解释抽屉，抽屉展示当前口径、摘要、分布统计和重点明细入口，再由底部按钮承接到评分明细、主体分析、主题分析、异常明细或规则流水。

## 6. 中部板块

### 6.1 监控主题评分态势

用于展示当前筛选范围下业务监控、专题监控各主题的评分、风险主体数量和异常情况。

展示字段包括监控主题、平均得分、风险等级、高风险主体数、低分指标数、异常数据数、阻断拦截数、处置闭环率。

点击某个监控主题后，地图、主体排行、短板证据和底部明细均切换到该主题口径，并高亮当前选中主题。

### 6.2 全辖综合风险分布

地图使用 ECharts 地图能力加载两级湖南 GeoJSON，并作为页面核心空间分析入口：

```text
省级市州视图：https://geo.datav.aliyun.com/areas_v3/bound/430000_full.json
市级区县视图：https://geo.datav.aliyun.com/areas_v3/bound/430000_full_district.json
```

默认进入省级视图，展示湖南省各市州边界、市州名称和综合风险染色，不允许只显示湖南省整体外框。点击市州后进入对应市级视图，只展示该市州及下辖区县；点击区县后高亮当前区县，不再继续下钻。地图标题下方展示当前区划、当前层级和染色口径；默认全省状态不展示“返回全省”，进入市州、区县或省本级口径后再展示返回入口。省本级不强行绘制到地理地图上，只作为快捷口径入口。

默认按综合风险染色，可切换综合风险、评价得分、高风险主体数、异常数据数、阻断拦截数。综合风险基于评分结果形成，异常数据和拦截数量只作为辅助口径。地图风险图例收敛为三档，使用柔和但明确的递减色阶：

```text
高风险｜中风险｜低风险｜暂无数据
```

省级视图悬浮市州时展示区划名称、综合得分、风险等级、全省排名、高风险主体数、高风险主题数、异常数据数、阻断拦截数、处置闭环率、主要低分主题。市级视图悬浮区县时展示区县名称、所属市州、综合得分、风险等级、市内排名、高风险主体数、异常数据数、阻断拦截数、处置闭环率、主要扣分原因。地图默认标签只保留精简区划名，字号和色彩弱化，详细信息通过悬浮 tooltip 展示。

顶部行政区划筛选与地图双向联动：

- 选择“湖南省全辖”时，地图回到省级市州视图。
- 选择某市州时，地图进入该市州区县视图。
- 选择某区县时，地图进入其所属市州区县视图，并高亮该区县。
- 点击地图市州或区县时，同步更新当前位置、指标卡、监控主题评分态势、主体风险排行、评分短板与规则证据、底部明细追溯。

地图支持缩放、平移和重置视图。缩放、平移、重置只改变地图视觉，不改变统计口径；只有顶部区划筛选、点击市州、点击区县才改变页面统计口径。若区划暂无评分数据，地图以浅灰展示并在 tooltip 提示“暂无评分数据”；若地图数据加载失败，保留降级区划卡片，不影响周围板块按当前 mock 口径展示。

### 6.3 主体风险排行

该板块不能取消，用于展示当前范围内风险最高的主体。

字段包括排名、主体名称、所属区划、主体类型、综合得分、风险等级、低分主题、主要扣分原因、异常数据数、处置闭环率。

点击主体后，底部切换到该主体的主体主题评分明细，并同步展示该主体相关短板；“查看详情”作为进入主体分析详情页的预留入口。

### 6.4 评分短板与规则证据

用于解释当前区划、主体或主题为什么风险高。

字段包括低分指标、指标得分、影响主体数、关联规则数、异常数据数、阻断拦截数、主要扣分原因、处置闭环率。

点击低分指标后，底部切换到“指标扣分证据”页签；“查看指标详情”作为进入评价体系指标详情页的预留入口。

## 7. 明细追溯

底部明细追溯替换旧版底部多个卡片，采用整行页签表格：

- 主体主题评分明细：主体名称、所属区划、主体类型、监控分类、监控主题、主题得分、风险等级、低分指标、异常数据数、阻断拦截数、处置闭环率、操作。
- 指标扣分证据：主体名称、监控主题、一级指标、二级指标、指标得分、扣分影响、扣分原因、关联规则、异常数据数、是否计入评分、操作。
- 异常数据明细：触发时间、行政区划、主体名称、监控分类、监控主题、规则名称、预警级别、处理方式、涉及金额、当前状态、关联评价指标、操作。
- 规则拦截流水：执行时间、规则编码、规则名称、所属监控主题、执行结果、命中数量、拦截数量、失败原因、操作。

## 8. 联动规则

- 顶部统计时间、行政区划、监控分类、监控项变化后，刷新总览指标、主题评分态势、地图、主体排行、评分短板和明细追溯。
- 点击总览指标卡后，先打开右侧指标解释抽屉，不直接跳转；抽屉结构统一为标题、当前口径、摘要、分布统计、重点条目和底部动作。
- 点击地图区划后，页面切换为该区划下的数据口径。
- 点击监控主题后，地图展示该主题在各区划的综合风险，主体排行展示该主题下高风险主体，短板证据展示该主题低分指标。
- 点击主体后，底部明细聚焦该主体，短板证据展示该主体相关低分指标。
- 点击低分指标后，底部切换到指标扣分证据，并可进一步查看关联异常和规则流水。
- 点击总览指标时，高风险主体数、高风险主题数、异常数据数、阻断拦截数、处置闭环率分别联动到对应明细或排序视角。

## 9. 视觉规范

- 继续沿用财会监督 V2.0 的蓝白色系、浅色背景、圆角卡片、轻阴影、弱边框风格。
- 不使用深色大屏，不使用大面积强色块。
- 页面按 1920 × 1080 一屏优先设计，筛选区、指标卡、中部分析卡和底部明细保持紧凑但不拥挤。
- 地图、卡片、列表之间保持统一间距和对齐；中部卡片标题只保留一个主标题，不再同时显示小标题和大标题。
- 筛选区复用“全局总览2”的紧凑筛选风格，标签和值靠近，所有筛选控件放在同一行；下拉箭头使用去原生样式后的 CSS 小三角，右侧仅增加重置图标按钮，减少纵向占用。
- 指标卡复用“全局总览2”的入口卡底层质感，但信息压缩为“左上标题 + 右下数值单位”，高度尽量降低，不展示周期变化、AI 结论常显标签和点击查看常显文案。
- 规则触发和异常数据在视觉上弱于综合得分、主体风险和主题评分结果，避免把证据数据误读为顶层主线。

## 10. 实现边界

- 当前仅完成前端静态原型、mock 数据和本地状态联动。
- 不接真实接口，不实现真实业务计算，不新增后端、不做权限或复杂校验。
- 不新增完整主体分析、主题分析或指标详情页面，仅保留进入详情的按钮入口。
- 本页不展示旧版“风险事项从哪里来”和“智能研判与建议”主区域；后续可作为扩展模块单独设计。
