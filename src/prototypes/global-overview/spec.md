# 全辖监督分析规格文档

## 1. 页面定位

本页面是全景分析下的“全辖监督分析”原型，用于在当前统计范围内汇总日常监督评分、规则触发、异常拦截和处置闭环结果，识别区划、主体和监控主题的风险高低及主要成因。

页面主线为：

```text
区划综合风险 -> 主体综合风险 -> 监控主题评分短板 -> 指标扣分原因 -> 规则/异常数据证据
```

核心判断依据是评分结果，规则触发、异常数据、阻断拦截和处置闭环作为解释评分结果的证据，不再沿用旧版“风险主体、风险主题、风险事项、待办环节事项”等泛风险指标做顶层主线。

## 2. 页面结构

- 顶部系统导航：复用公共 `TopBar`，保留当前系统级导航、搜索、消息和用户区风格。
- 标题说明区：标题为“全辖监督分析”，说明文案为“以评价体系得分为主线 识别风险高低，以异常率、审核质量、闭环效率解释扣分原因。”标题与说明同处一行，右侧展示当前位置、统计维度、当前监控主题和数据更新时间。
- 全局筛选区：所有全局筛选保持一行展示，最终顺序为统计时间、行政区划、监控分类、监控主题、主体类型、主体名称；监控分类和监控主题使用两级选择控件，不铺开展示全部选项。
- 总览指标区：展示 5 个核心指标，包括风险指数/评价得分（动态切换）、高风险主体数、低分监控主题数、异常率、审核退回率、闭环率。首张卡随监控主题选择动态切换名称和解释口径，百分比指标悬停展示分子分母。
- 中部分析区：左侧“监控主题评分态势”、中间“全辖综合风险分布”湖南地图、右侧“主体风险排行”和“评分短板与规则证据”。
- 底部明细区：整行展示“明细追溯”，通过页签承接主体主题评分、指标扣分证据、异常数据、规则拦截流水。

## 3. 筛选设计

### 3.1 第一行全局筛选

- 统计时间：今日、昨日、本月、本季度、本年、自定义。
- 自定义时间范围：仅统计时间选择“自定义”时展示开始日期和结束日期。
- 行政区划：湖南省全辖、省本级、市州、区县等 mock 选项；选择后立即刷新当前页面 mock 口径。
- 主体类型：全部、财政部门、主管部门、预算单位、省直单位、责任单位；默认值为全部。
- 主体名称：默认值为全部，根据行政区划、监控分类、监控主题、主体类型联动生成可选主体。
- 刷新按钮：位于筛选行最右侧，复用全辖监督分析的轻量胶囊按钮样式，展示刷新图标和“刷新”文字；点击仅刷新当前本地视图，不恢复筛选默认值。
- 数据更新时间：固定 mock 文案 `2026年5月14日 15:00`，只在标题区右侧展示，不在筛选区重复展示。

### 3.2 第二行监控分类

监控分类作为一级选择，仅包含：

- 全部
- 业务监控
- 专题监控

处理方式、预警级别、规则类型、处理状态等细分条件不放顶部，后续放在对应板块或明细页签内。

### 3.3 第三行监控主题

- 选择“全部”时，监控主题下拉中按“业务监控”和“专题监控”分组展示。
- 选择“业务监控”时，展示基础信息、项目库、预算编制、预算批复、预算调整调剂、指标管理、预算执行、资产管理、会计核算。
- 选择“专题监控”时，展示地方政府债务、高标准农田建设资金使用、行政事业单位国有资产处置、减税降费政策落实、违规返还财政收入、三保、三公、一卡通。
- 点击监控主题后，地图、主体排行、评分短板和明细追溯同步切换到该监控主题口径。

## 4. 数据口径

### 4.1 基础分析单元

前端 mock 数据以“主体 + 监控主题 + 评分结果”为最小分析单元，字段包括：

- `subjectName`
- `regionName`
- `subjectType`
- `monitorCategory`
- `monitorTheme`
- `themeScore`
- `themeWeight`
- `subjectWeight`
- `riskLevel`
- `lowScoreIndicators`
- `abnormalCount`
- `interceptCount`
- `closedLoopRate`
- `mainDeductionReason`

主体综合得分由该主体下多个监控主题得分按 `themeWeight` 汇总；当前 mock 阶段使用等权，字段预留后续真实权重。区划综合得分由区划内主体综合得分按 `subjectWeight` 汇总；当前 mock 阶段同样使用等权。

### 4.2 风险等级

风险等级只由评分划分，异常数量只作为解释证据：

- 90 分及以上：低风险
- 80-90 分：较低风险
- 70-80 分：中风险
- 60-70 分：较高风险
- 60 分以下：高风险

### 4.3 Mock 数据范围

区划数据覆盖湖南场景：长沙市、株洲市、湘潭市、衡阳市、邵阳市、岳阳市、常德市、张家界市、益阳市、郴州市、永州市、怀化市、娄底市、湘西州、省本级。

主体数据包括长沙市财政局、株洲市财政局、衡阳市财政局、省直预算单位A、省直预算单位B、某区县财政局、某主管部门等。

规则示例包括无预算支付拦截规则、超预算支付预警规则、三保资金保障预警规则、债务风险指标异常规则、资产处置审批完整性规则、预算执行进度异常规则、会计核算科目使用异常规则。

## 5. 总览指标

总览指标保留横向统计卡样式，但内容改为评价主线和比例型风险指标组合。顶部核心指标卡片从 6 个调整为 5 个：

### 5.1 卡片名称动态切换

- **风险指数/评价得分（首张卡）**：当"监控主题 = 全部"时，卡片名称为"风险指数"；当选择具体监控主题时，卡片名称为"评价得分"。
- 风险指数含义：当前统计范围内，基于多个日常监督主题的风险情况汇总形成的综合风险判断结果，用于全局态势判断，不等同于某一个评价体系的直接得分。
- 评价得分含义：当前区划 / 当前主体范围 × 当前监控主题，评分对象明确，可以作为该主题的评价得分展示。

### 5.2 卡片文案示例

监控主题 = 全部：
```text
风险指数
72.2
较高风险
基于多主题风险汇总
```

监控主题 = 预算执行：
```text
评价得分
72.2
预算执行｜较高风险
较上期下降 2.1
```

### 5.3 五个核心指标

- **风险指数/评价得分**：首张卡，动态切换名称，展示风险判断和较上期变化
- **高风险主体数**：风险等级为高 / 较高的主体数量
- **低分监控主题数**：得分低于阈值的监控主题数
- **异常率**：异常数据数 / 应检测数据总数，比例型风险指标
- **审核退回率**：审核退回事项数 / 已提交审核事项数，比例型风险指标
- **闭环率**：已闭环事项数 / 应闭环事项数，反映日常监督发现事项的最终处理完成情况

### 5.4 悬停说明功能

风险指数悬停说明：
```text
指标名称：风险指数
口径说明：基于当前统计范围内多个日常监督主题的风险情况汇总形成。
参考因子：低分主题数、最低主题得分、异常率、审核退回率、闭环率、超期未闭环情况等。
说明：该指标不是单一主题评价得分，不直接等同于评价体系得分。
统计范围：本月 / 湖南省全辖 / 日常监督全部主题
```

评价得分悬停说明：
```text
指标名称：评价得分
口径说明：当前监控主题下的评价体系计算结果。
当前主题：预算执行（示例）
评分对象：当前统计范围内的主体 × 当前监控主题
得分来源：当前监控主题日常监督评价体系
统计范围：本月 / 湖南省全辖 / 当前监控主题
```

百分比指标悬停说明（异常率、审核退回率、闭环率）：
```text
异常率悬停
异常率 = 异常数据数 / 应检测数据总数 × 100%
分子：异常数据数 1,548 条
分母：应检测数据总数 18,936 条
含义：反映数据检测发现的异常占比。
去重规则：同一主体、同一监控主题、同一规则、同一业务单据只计一次

审核退回率悬停
审核退回率 = 审核退回事项数 / 已提交审核事项数 × 100%
分子：审核退回事项 126 条
分母：已提交审核事项 1,420 条
含义：退回率偏高，说明材料完整性、说明质量或整改反馈质量不足。

闭环率悬停
闭环率 = 已闭环事项数 / 应闭环事项数 × 100%
分子：已闭环事项 1,042 条
分母：应闭环事项 1,286 条
含义：反映日常监督发现事项的最终处理完成情况。
```

### 5.5 卡片交互

卡片在"全局总览2"的指标入口卡质感基础上保持紧凑高度，常显标题、弱化说明、数值及单位。标题固定在左上角并预留长标题单行省略空间；数值和单位固定在右下角，右对齐展示，长数字从右向左占位并单行省略。鼠标悬停数值时展示该值怎么来的，包括计算口径、构成项、分子分母、说明和统计范围；悬浮说明向下展开，不遮挡顶部导航、页面标题和筛选信息。卡片本身只保留关键判断，不堆叠完整说明。首张卡展示风险判断和较上期变化：监控主题为"全部"时示例为"风险指数 72.2 / 较高风险 / 较上期上升 3.2"；选择"预算执行"等具体主题时示例为"评价得分 72.2 / 预算执行｜较高风险 / 较上期下降 2.1"。点击指标卡先打开指标解释抽屉，抽屉按“当前值怎么来 / 其他相关项 / 具体数据明细”组织信息。

### 5.6 指标解释抽屉

指标抽屉不再把所有信息平铺在同一层级，统一采用三段结构：

- 当前值怎么来：顶部重点展示当前指标值、风险判断或状态标签、计算口径、数据来源；比例类指标展示分子与分母，主体/主题类指标展示去重或阈值规则。
- 其他相关项：以紧凑统计格展示该指标相关的辅助项，例如覆盖主体数、覆盖主题数、涉及区划数、风险构成、未闭环数、超期数等。
- 具体数据明细：底部列表展示可点击的主体、主题、异常、扣分或闭环明细；点击后联动到底部明细表或切换页面筛选口径。

抽屉字体层级要求：主指标值最大，标题和标签次之，说明文字弱化；统计格使用浅底、弱边框和稳定高度，避免大段说明和统计数字混排。

## 6. 中部板块

### 6.1 监控主题评分态势

用于展示当前筛选范围下业务监控、专题监控各主题的评分、风险主体数量和异常情况。

展示字段包括监控主题、平均得分、风险等级、高风险主体数、低分指标数、异常数据数、阻断拦截数、处置闭环率。

点击某个监控主题后，地图、主体排行、短板证据和底部明细均切换到该主题口径，并高亮当前选中主题。

### 6.2 全辖综合风险分布

地图使用 ECharts 地图能力加载两级湖南 GeoJSON，并作为页面核心空间分析入口：

```text
省级市州视图：https://geo.datav.aliyun.com/areas_v3/bound/430000_full.json
市级区县视图：https://geo.datav.aliyun.com/areas_v3/bound/430000_full_district.json
```

默认进入省级视图，展示湖南省各市州边界、市州名称和综合风险染色，不允许只显示湖南省整体外框。点击市州后进入对应市级视图，只展示该市州及下辖区县；点击区县后仍保留该市州区县地图并高亮当前区县，不再继续展示下级地图或主体大列表。地图标题下方展示当前区划、当前层级和主体类型，例如“当前区划：湖南省全辖｜当前层级：市州分布｜主体类型：全部”“当前区划：张家界市｜当前层级：区县分布｜主体类型：全部”“当前区划：张家界市 / 武陵源区｜当前层级：区县分布｜主体类型：全部”。默认全省状态不展示"返回全省"，进入市州、区县或省本级口径后再展示返回入口。省本级不强行绘制到地理地图上，只作为快捷口径入口。

默认按综合风险染色，可切换：风险指数、评价得分、异常率、审核退回率、闭环率。首张卡片的名称变化与地图右上角第一个切换项同步：监控主题 = 全部时显示"风险指数｜异常率｜退回率｜闭环率"；监控主题 = 具体主题时显示"评价得分｜异常率｜退回率｜闭环率"。异常率和审核退回率基于评分结果形成，闭环率用于展示处置完成情况。地图风险图例收敛为三档，使用柔和但明确的递减色阶：

```text
高｜中｜低
```

地图区域染色必须与左下角图例保持一致：高为柔和红、中为柔和橙、低为柔和绿；不展示“暂无”图例。地图正常态只允许这三种色阶，不能再出现第四种风险色。

省级视图悬浮市州、市级视图悬浮区县时，统一保留这组字段：风险指数、全省排名、高风险主体、高风险主题、最低主题得分、异常率、退回率、闭环率。异常率、退回率、闭环率均展示分子分母，格式示例为“异常率：1.2%（104 / 8642）”“退回率：5.23%（38 / 726）”“闭环率：86.7%（90 / 104）”，不得出现“86.7%%”。地图默认标签只保留精简区划名，字号和色彩弱化，详细信息通过悬浮 tooltip 展示。

顶部行政区划筛选与地图双向联动：

- 选择“湖南省全辖”时，地图回到省级市州视图。
- 选择某市州时，地图进入该市州区县视图。
- 选择某区县时，地图仍展示所属市州区县分布，并高亮该区县；页面只切换统计口径，不出现主体大列表。
- 点击地图市州或区县时，同步更新当前位置、指标卡、监控主题评分态势、主体风险排行、评分短板与规则证据、底部明细追溯。
- 点击主体排行或在“主体名称”筛选中选择具体主体时，地图高亮该主体所属区划；地图区域调整为主体风险摘要；底部明细只展示该主体相关数据。

地图支持缩放、平移和重置视图。缩放、平移、重置只改变地图视觉，不改变统计口径；只有顶部区划筛选、点击市州、点击区县才改变页面统计口径。若区划暂无评分数据，地图以浅灰展示并在 tooltip 提示“暂无评分数据”；若地图数据加载失败，保留降级区划卡片，不影响周围板块按当前 mock 口径展示。

### 6.3 主体风险排行

该板块不能取消，用于展示当前范围内风险最高的主体。

默认展示 20 个主体，排行卡片位于地图右下角并保持原位置。卡片高度加高，常显字段只保留排名和主体名称；所属区划、主体类型、风险指数、异常率、退回率、闭环率、扣分说明等主体信息通过悬停查看，悬浮内容格式为“风险指数 88｜较低风险”“异常率 8.0%｜较高风险”“退回率 8.9%｜中风险”“闭环率 81.1%｜中风险”。

点击主体后，底部切换到该主体的主体主题评分明细，地图高亮该主体所属区划，中间地图区域展示主体风险摘要，并同步展示该主体相关短板；“查看详情”作为进入主体分析详情页的预留入口。

### 6.4 评分短板与规则证据

用于解释当前区划、主体或主题为什么风险高。

字段包括低分指标、指标得分、影响主体数、关联规则数、异常数据数、阻断拦截数、主要扣分原因、处置闭环率。

点击低分指标后，底部切换到“指标扣分证据”页签；“查看指标详情”作为进入评价体系指标详情页的预留入口。

## 7. 明细追溯

底部明细追溯替换旧版底部多个卡片，采用整行页签表格：

- 主体主题评分明细：主体名称、所属区划、主体类型、监控分类、监控主题、主题得分、风险等级、低分指标、异常数据数、阻断拦截数、处置闭环率、操作。
- 指标扣分证据：主体名称、监控主题、一级指标、二级指标、指标得分、扣分影响、扣分原因、关联规则、异常数据数、是否计入评分、操作。
- 异常数据明细：触发时间、行政区划、主体名称、监控分类、监控主题、规则名称、预警级别、处理方式、涉及金额、当前状态、关联评价指标、操作。
- 规则拦截流水：执行时间、规则编码、规则名称、所属监控主题、执行结果、命中数量、拦截数量、失败原因、操作。

当主体名称筛选为具体主体，或点击主体风险排行中的某一主体后，底部四类明细均收敛为该主体相关数据；无法直接归属主体的规则流水按该主体涉及监控主题过滤。

## 8. 联动规则

- 顶部统计时间、行政区划、监控分类、监控主题变化后，刷新总览指标、主题评分态势、地图、主体排行、评分短板和明细追溯。
- 点击总览指标卡后，先打开右侧指标解释抽屉，不直接跳转；抽屉结构统一为标题、当前值怎么来、其他相关项、具体数据明细。
- 点击地图区划后，页面切换为该区划下的数据口径。
- 点击监控主题后，地图展示该主题在各区划的综合风险，主体排行展示该主题下高风险主体，短板证据展示该主题低分指标。
- 点击主体后，底部明细聚焦该主体，短板证据展示该主体相关低分指标。
- 点击低分指标后，底部切换到指标扣分证据，并可进一步查看关联异常和规则流水。
- 点击总览指标时，高风险主体数、高风险主题数、异常数据数、阻断拦截数、处置闭环率分别联动到对应明细或排序视角。

## 9. 视觉规范

- 继续沿用财会监督 V2.0 的蓝白色系、浅色背景、圆角卡片、轻阴影、弱边框风格。
- 不使用深色大屏，不使用大面积强色块。
- 页面按 1920 × 1080 一屏优先设计，筛选区、指标卡、中部分析卡和底部明细保持紧凑但不拥挤。
- 地图、卡片、列表之间保持统一间距和对齐；中部卡片标题只保留一个主标题，不再同时显示小标题和大标题。
- 筛选区复用“全局总览2”的紧凑筛选风格，标签和值靠近，所有筛选控件放在同一行；下拉箭头使用去原生样式后的 CSS 小三角，右侧仅增加刷新按钮，减少纵向占用。
- 指标卡复用“全局总览2”的入口卡底层质感，但信息压缩为“左上标题 + 右下数值单位”，高度尽量降低；首张卡补充风险判断和较上期变化，其他卡片不展示周期变化、AI 结论常显标签和点击查看常显文案。
- 规则触发和异常数据在视觉上弱于风险指数/评价得分、主体风险和主题评分结果，避免把证据数据误读为顶层主线。

## 10. 实现边界

- 当前仅完成前端静态原型、mock 数据和本地状态联动。
- 不接真实接口，不实现真实业务计算，不新增后端、不做权限或复杂校验。
- 不新增完整主体分析、主题分析或指标详情页面，仅保留进入详情的按钮入口。
- 本页不展示旧版“风险事项从哪里来”和“智能研判与建议”主区域；后续可作为扩展模块单独设计。
