# Agent智能体配置规格文档

## 1. 业务与功能

### 1.1 核心目标

Agent 页面作为“扩展功能”的智能体配置入口，面向财会监督管理岗、规则管理岗和核查人员，先搭建可演示的静态配置框架。

页面回答四个问题：
- 当前有哪些财政监督智能体；
- 每个智能体的角色、模型、指令、知识、工具和护栏如何配置；
- 智能体运行时如何追踪调用链路和效果；
- 发布前哪些配置需要人工复核。

本页仅为静态前端原型，不接真实模型、接口、数据库、工具调用或权限系统。

### 1.2 功能清单

- 顶部导航：复用公共 TopBar，并在“扩展功能”菜单中新增 Agent 入口。
- 概览指标：展示已配置智能体、工具连接、平均成功率和待复核项。
- 智能体目录：按业务场景选择“监督研判 Agent、规则编排 Agent、整改督办 Agent、材料核验 Agent”。
- 配置视图：展示系统指令、自主级别、记忆策略、通用配置链路、工具能力、知识来源和护栏策略。
- 运行观测：展示模拟运行次数、成功率、平均耗时以及意图识别、知识检索、工具调用、护栏校验、输出生成链路。
- 发布检查：展示发布前检查清单、已完成项、待复核项和当前启用工具数量。
- 右侧摘要：展示适用场景、已选工具和通用 Agent 配置方案映射。

### 1.3 交互要点

- 点击智能体目录卡片：切换中间配置详情、运行观测和右侧摘要。
- 点击顶部“试运行”：切换到运行观测视图，不触发真实运行。
- 点击顶部“发布检查”：切换到发布检查视图。
- 点击工具能力项：模拟启用或停用工具，仅影响当前页面展示。
- 点击配置视图、运行观测、发布检查页签：切换对应内容。

## 2. 内容规划

### 2.1 信息架构

```text
Agent智能体配置
├── TopBar
├── 页面标题与快捷操作
├── Agent 概览指标
├── 主体三栏布局
│   ├── 智能体目录
│   ├── 配置工作区
│   │   ├── 当前智能体摘要
│   │   ├── 配置视图
│   │   ├── 运行观测
│   │   └── 发布检查
│   └── 配置摘要与通用方案映射
```

### 2.2 数据来源

- 数据类型：智能体配置、工具能力、知识来源、运行链路、发布检查清单。
- 数据源：本地生成 mock 数据。
- 关键字段：
  - `name`：智能体名称。
  - `scenario`：适用业务场景。
  - `instruction`：系统指令摘要。
  - `model`：模型策略。
  - `autonomy`：自主级别。
  - `memory`：记忆策略。
  - `guardrails`：护栏策略。
  - `tools`：工具名称、状态、调用范围。
  - `successRate`：模拟运行成功率。
  - `lastRun`：模拟最近运行时间。

### 2.3 参考方案

参考网上官方智能体配置文档，将通用方案收敛为：
- Instructions：系统指令、角色、任务边界和输出格式。
- Tools：工具声明、工具白名单、审批条件和调用范围。
- Knowledge / Memory：知识来源、上下文记忆、数据状态和更新频率。
- Guardrails：敏感数据、风险结论、人工确认和来源追溯。
- Handoffs / Workflow：多智能体或多步骤流转。
- Observability：运行记录、调用链路、效果指标和待复核项。

## 3. 布局与结构

### 3.1 整体布局

- 布局模式：大屏三栏布局。
- 容器宽度：`min(1900px, calc(100vw - 28px))`。
- 左栏：智能体目录，固定宽度约 280px。
- 中栏：配置工作区，自适应剩余宽度，是页面主视觉重心。
- 右栏：配置摘要和通用方案映射，固定宽度约 320px。
- 顶部：标题区 + 概览指标，保持与现有财会监督页面的信息密度一致。

### 3.2 响应式适配

- 桌面端（≥1400px）：三栏布局，配置链路六列展示。
- 中等桌面（1024-1399px）：左栏 + 中栏，右侧摘要下移成双列。
- 平板端（720-1023px）：单栏堆叠，概览和配置卡片双列展示。
- 移动端（<720px）：全部单列，按钮和页签撑满容器。

## 4. 视觉规范

### 4.1 设计规范来源

设计规范来源：页面内 Tailwind/CSS 样式 `/src/prototypes/agent/style.css` + 内置 `interface-design`。

### 4.2 自定义设计要点

- 用户明确要求无边框设计：页面不使用显性描边分隔，依靠柔和底色、半透明层、阴影、色彩洗底和间距建立层级。
- 视觉基调延续财会监督V2.0的浅蓝、政务蓝、白色玻璃面板和高密度后台风格。
- Agent 配置不使用营销化科技紫大面积渐变，紫色仅用于“材料核验 Agent”的辅助状态。
- 页面首屏展示配置对象和可操作页签，不做说明型落地页。
- 文案保持政务监督语气，强调来源、审批、脱敏、人工确认和可追溯。

### 4.3 组件状态

- 默认态：白色半透明面板、浅蓝底色、柔和阴影，无显性边框。
- 悬停态：轻微上移、背景变亮、阴影增强。
- 选中态：通过更亮白底、阴影和弱色洗底表达，不使用描边。
- 工具启用态：工具行背景加强；再次点击可取消启用。
- 发布检查完成态：绿色浅底；待复核态：琥珀浅底。
- 移动端：按钮、页签、卡片自动堆叠，避免重叠和横向溢出。
