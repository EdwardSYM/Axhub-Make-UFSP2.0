# 甘肃反哺建议检索原型规格

## 1. 页面定位

本页面是“案例库（AI改造）（甘肃）→ 智能检索 → 反哺建议检索”的独立原型入口，用于检索从典型案例中智能提炼形成的反哺建议。

反哺建议面向三类业务方向：

- 政策优化：从案例中的口径差异、制度缺口和重复问题提炼政策完善建议。
- 问题整改：从有效整改措施和整改闭环中提炼可复用的整改机制。
- 规则设置：从高频风险和有效控制措施中提炼业务校验或系统规则建议。

页面复用案例智能检索的首页、结果页和详情页布局及交互基线，但标题、检索范围、筛选字段、结果数据和详情内容均使用反哺建议独立口径。

## 2. 检索首页

- 页面标题为“反哺建议检索”。
- 主搜索框左侧提供反哺方向下拉选择，选项为“政策建议 / 规则建议 / 问题整改”，不设置“全部”；默认选择“政策建议”。选择后推荐检索词和结果列表按对应反哺方向联动。
- 主检索覆盖建议标题、建议内容、建议类型、建议标签、来源典型案例以及政策、整改、规则相关自然语言描述。
- 推荐检索词围绕政策口径、整改机制、规则设置和典型案例提炼场景。
- 可检索范围展示反哺建议数量、来源典型案例数量和三类反哺方向。
- 页面明确说明建议来源于典型案例的智能提炼，不与一般案例检索范围混用。

## 3. 检索结果

- 常驻筛选项：建议类型、适用范围、提炼时间、采纳状态、建议标签。
- 首页搜索类型选择与结果页“建议类型”筛选共用同一状态，返回首页后保留当前选择。
- 更多筛选项：建议编号、来源典型案例、提炼方式。
- 结果摘要展示建议标题、建议编号、建议类型、适用范围、提炼时间、采纳状态、来源典型案例数量、建议标签、字段级命中内容和匹配原因。
- 排序支持相关度优先、提炼时间最新、提炼时间最早。
- 单条结果支持“建议解读”，从为什么匹配、提炼共性、适用边界和建议成熟度四个角度展示本地 mock 分析。

## 4. 建议详情

- 详情页标题为“反哺建议详情”。
- 内容定位分为“命中内容 / 建议详情 / 提炼依据”。
- 建议信息展示：建议编号、建议类型、采纳状态、适用范围、提炼时间、提炼方式、来源典型案例数量。
- 反哺建议展示：建议概述、建议内容、预期效果、适用条件、建议标签。
- 提炼依据展示典型案例共性特征和来源典型案例列表，支持理解建议是如何从典型案例中形成的。
- 右侧保留匹配原因和相似建议入口。

## 5. 数据与边界

- 页面路由为 `/prototypes/gansu-feedback-suggestion-search`。
- 左侧菜单统一复用 `src/components/case-library-feature-menu`，当前页面选中“反哺建议检索”。
- Axure 变量 `feature_key` 为 `feedback_suggestion_search`，`feature_name` 为“反哺建议检索”。
- 数据、筛选、建议解读和详情均为本地 mock 演示，不接入真实典型案例提炼、政策研判、整改管理、规则配置、数据库或权限接口。
