# UFSP2.0 业务页面可视化基线

## 1. 业务与功能

### 1.1 核心目标

将已确认的业务列表页和全页面表单规范集中到一个可运行样板中，供用户整体查看和标注异常，不再逐项确认字号、尺寸、颜色与间距。

### 1.2 用户任务

- 查看完整页面层级是否符合财会监督 V2.0。
- 区分公共 TopBar、系统功能菜单、业务树和列表工作区。
- 查看按钮、输入框、页签、工具栏、表格、分页和表单页头是否保持同一套组件比例。
- 从列表点击“新增”进入全页面表单，再通过返回按钮回到列表。

### 1.3 交互

- 系统功能菜单支持展开 / 收起。
- 业务树支持展开 / 收起和节点选择。
- 状态页签支持切换。
- 查询框展示项目标准聚焦态。
- “新增”进入表单样板；返回或保存回到列表样板。
- 操作只用于静态原型反馈，不请求真实接口。

## 2. 内容规划

- 使用案例库作为视觉内容载体，因为其列表、业务树、表单页头和工具栏已被登记为强基准 / 局部基准。
- 列表数据、分类树和表单字段均为本地 mock。
- 提示词管理页面仍在校准，不作为本样板的视觉来源。

## 3. 布局与结构

### 3.1 列表样板

```text
公共 TopBar（64px）
└── 页面工作区（16px 外边距与间距）
    ├── 系统功能菜单（272px / 收起 64px）
    └── 白色业务面板
        ├── 状态页签（48px，跨业务树和列表）
        └── 内容区
            ├── 业务树（250px / 可收起）
            └── 列表工作区
                ├── 工具栏（56px）
                ├── 选择提示（32px）
                ├── 表格（32px 表头和行）
                └── 分页（56px）
```

### 3.2 表单样板

```text
公共 TopBar（64px）
└── 页面工作区
    ├── 系统功能菜单
    └── 白色业务面板
        ├── 表单页头（64px）
        └── 分组表单（四列标准栅格，长文本整行）
```

## 4. 视觉方向

- **Intent**：面向财会监督业务人员和原型维护人员，快速判断页面结构和组件是否统一；感受应专业、紧凑、克制、可靠。
- **Palette**：顶部导航深蓝 `#2A487E → #4A6FA8`；业务主操作蓝 `#1890FF`；表头蓝灰 `#6A8DC4`；浅灰蓝画布 `#F5F8FF`；白色工作区。
- **Depth**：外层面板极弱阴影，内部以留白和必要分隔线组织；不使用厚边框和强投影。
- **Surfaces**：外部浅灰蓝画布、白色系统菜单、白色业务面板、浅蓝选中反馈。
- **Typography**：系统字体；控件和表格以 `14px` 为主，辅助信息 `12-13px`。
- **Spacing**：以 `4px` 为基础单位；页面边距和列间距 `16px`；控件间距 `8px`。

## 5. 组件基线

- 按钮、输入框、页签、表格、分页按 `src/docs/业务页面设计规范.md`。
- 系统功能菜单按问题库 / 案例库确认样式：44px 行高、30px 图标槽、低饱和蓝灰选中态。
- 工具栏图标复用问题库专业 SVG 原件。
- 输入框取消浏览器原生 outline，聚焦使用弱蓝阴影。
- 表格表头 `#6A8DC4`、白字、32px 行高；表体 32px 行高。

## 6. 使用边界

- 本页面是批量视觉校准样板，不是新的业务模块。
- 本轮不修改问题库、案例库、考评库和提示词管理现有页面。
- 用户确认样板后，再决定抽取公共组件和同步旧页面的范围。
