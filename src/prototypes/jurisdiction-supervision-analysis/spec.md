# 全辖监督分析规格文档

## 1. 页面定位

本页面是全景分析下的“全辖监督分析”独立原型，当前阶段实现“全辖监督分析 - 日常监督默认页”，并补充切换到“专项监督”后的专项问题全辖分析形态。

页面面向领导和管理岗，用于在当前行政区划范围内识别：

- 当前全辖范围内哪些区划需要关注；
- 当前哪些日常监督主题需要关注；
- 关注程度在地图上如何分布；
- 当前日常监督规则发现了多少预警疑点；
- 已确认问题数量和金额规模如何；
- 监督发现、确认问题和典型风险是否形成可复用案例成果；
- 规则触发、疑点核实和问题确认结果如何解释上方判断。
- 当监督分类切换为专项监督时，当前全辖范围内哪些区划专项问题较多、整改推进较慢、超期或退回较集中，哪些专项主题需要重点跟进，以及专项整改是否形成案例和成果沉淀。

本页不是业务办理页，不是规则库、问题库或评价体系的简单统计页。默认未选择具体主题时，日常监督使用静态原型口径的“综合表现分”辅助关注分层、颜色展示和排序；专项监督使用问题台账、整改状态、销号、超期、退回、督办和案例沉淀等 mock 字段辅助展示，不替代正式业务公式。

## 2. 默认口径

| 项目 | 当前口径 |
|---|---|
| 页面入口 | 全辖监督分析 |
| 行政区划 | 湖南省 |
| 监督分类 | 日常监督 |
| 统计时间 | 本月 / 本期 |
| 监督主题 | 全部日常主题 |
| 展示层级 | 省本级 + 各市州 |
| 地图层级 | 各市州 |

切换为专项监督时，默认口径为“湖南省全辖 / 专项监督 / 全部专项主题”，展示省本级 + 各市州的专项问题整改情况；选择一级专项分类或二级专项主题后，顶部卡片、左侧区划、地图、右侧专项主题和底部整改分析同步切换。选择本级节点或区县节点时仍跳转到独立本级监督分析页面。

## 3. 页面结构

页面按四层组织：

| 层级 | 区域 | 作用 |
|---|---|---|
| 第 0 层 | 顶栏 / 分析口径区 | 明确页面标题、核心筛选、统计时间、当前统计口径和数据更新时间 |
| 第 1 层 | 全辖概览卡片 | 日常监督概括风险关注态势；专项监督概括问题整改总盘 |
| 第 2 层 | 主分析区 | 左侧需关注区划，中间区划关注 / 整改分布，右侧需关注主题 / 专项主题 |
| 第 3 层 | 底部分析区 | 日常监督解释规则、疑点、问题和案例链路；专项监督解释问题分布、整改状态、超期、退回、督办和案例沉淀 |

核心浏览逻辑：

```text
先看当前全辖整体关注状态 -> 看哪些区划需要关注 -> 看地图分布和下钻 -> 看哪些主题需要关注 -> 用监控预警与明细追溯解释原因
```

页面边界：

- 本页面只处理区划全辖分析形态，中间板块展示本级卡片和下级区划地图。
- 行政区划筛选使用树形下拉展示，省级为一级，市州为可点击二级节点，市本级和区县为三级节点；不使用不可点击的城市分组标题，避免出现“长沙市标题 + 长沙市选项”的重复层级。全辖页自身只分析全辖节点。
- 点击本级卡片或区县等需要进入本级 / 单位形态的对象时，跳转到独立“本级监督分析”页面。
- 当前只使用前端静态 mock 数据，不接真实接口，不实现真实业务公式、权限或复杂校验。

## 4. 顶栏 / 分析口径区

顶栏不是复杂筛选器，只承担标题说明、核心筛选和当前统计口径声明。

字段：

- 标题：全辖监督分析。
- 说明：日常监督展示关注情况、区划分布和主题表现；专项监督展示问题整改、销号、超期、退回、督办和案例沉淀情况。
- 筛选顺序：统计时间放在最前，其后依次为行政区划、监督分类、监督主题和重置。
- 筛选下拉：统计时间、行政区划、监督分类、监督主题统一使用自定义下拉样式，保持相同的触发按钮、浮层圆角、阴影、选中态和层级覆盖规则。
- 行政区划：默认湖南省全辖，展开后保持省 / 市州 / 本级区县的层级缩进；市州节点本身可直接点击并切换到市州全辖口径，选择省本级、市本级或区县节点时进入本级监督分析。行政区划下拉浮层必须覆盖下方概览卡片，但低于顶部导航菜单浮层，不得遮挡全局导航菜单。
- 统计时间：默认本月，用于控制卡片、地图、列表和底部分析的统计周期；选择“自定义”后，在统计时间后方按原有筛选条风格直接展开“开始日期”和“结束日期”两个日期字段。日期字段点击后使用页面内自定义日历浮层，不使用浏览器原生日期下拉，以保持和全辖页筛选下拉一致的圆角、弱阴影、选中态和层级。
- 监督分类：默认日常监督；切换专项监督后进入专项问题全辖分析口径。
- 监督主题：默认全部日常主题，日常监督下按业务监控和专题监控分组展示；专项监督下按“重点领域整改、专项检查、审计问题整改、巡视问题整改”两级专项主题展示，并支持选择一级分类或具体二级专项主题。
- 重置：恢复默认筛选为湖南省全辖 / 日常监督 / 本月 / 全部日常主题。
- 当前统计口径：按统计时间、行政区划、监督分类、监督主题顺序展示；统计时间为自定义时展示“开始日期 至 结束日期”。
- 数据更新时间：展示系统数据刷新时点，不等同于统计时间。

顶部卡片默认不展示“较上期变化”，避免“上期”随统计时间变化产生解释争议。

## 5. 全辖概览卡片

默认多主题 × 多区划状态下，顶部使用 6 张宏观态势卡片：

| 卡片 | 展示含义 |
|---|---|
| 高关注区划数 | 当前口径下进入重点关注档的省本级或下级区划数量 |
| 高关注主题数 | 当前口径下平均分偏低、低分区划较多或问题证据集中的日常监督主题数量 |
| 预警疑点数量 | 当前日常监督规则识别出的预警疑点数量 |
| 确认问题数量 | 经核实确认的真实问题数量 |
| 确认问题金额 | 经核实确认的问题涉及金额 |
| 案例沉淀数 | 当前筛选口径下已入库、已发布或已审核待发布的案例沉淀数量 |

口径说明：

- “综合表现分”是原型展示口径：评价表现分 × 40% + 问题金额表现分 × 25% + 问题数量表现分 × 20% + 预警疑点表现分 × 15%。
- 关注分层：综合表现分 60 分以下为高关注，60–79 分为中关注，80 分及以上为低关注；顶部高关注卡片只统计高关注对象。
- 预警疑点是发现端线索，不等于确认问题。
- 顶部大数字遵循“数字大、单位小”的规范：确认问题金额拆分为大数字 + 小号“万元”；案例沉淀数拆分为大数字 + 小号“个”。
- 顶部卡片保持紧凑高度，指标标题适当加粗，常驻内容只展示指标名称和主数字，不常驻展示长说明文字；说明入口统一使用左下角对齐的标准“i”图标，悬停后展示指标含义、统计口径、计算方式、统计范围和补充说明，避免长说明与大数字重合。
- 顶部卡片数字区域独立右下对齐，标题和数字之间必须保留安全间距；长数字进入紧凑字号模式，只在数字区域内自适应，不得侵占左下角说明入口或标题区域。
- 顶部卡片说明浮层必须高于筛选条层级展示，避免悬停说明被筛选区、下拉触发器或重置按钮遮挡。
- 案例沉淀数是成果指标，不参与综合表现分计算；它不代表风险高低、问题多少或办理进度，只用于补齐“发现线索 -> 确认问题 -> 形成案例”的成果链路。
- 疑点转问题率、疑点核实完成率、高频规则数、待处理事项数、较上期变化不进入默认顶部卡片，放到底部分析或后续趋势模块。

卡片抽屉采用“标题区 + 主摘要 + 弱口径说明 + 摘要指标 + 明细列表 / 表格”的结构。计算口径必须完整展示，允许自然换行，不做省略号截断；抽屉口径条只展示业务口径 / 公式，不展示“mock 数据”等原型说明，避免干扰业务判断。

切换专项监督后，顶部卡片改为专项整改闭环口径：

| 卡片 | 展示含义 |
|---|---|
| 需关注区划 | 按问题数量、问题金额、未销号、超期、退回、督办和案例沉淀识别需关注区划 |
| 问题总数 | 当前统计时间和专项主题范围内的问题台账数量 |
| 问题金额 | 当前专项问题涉及金额合计 |
| 未销号问题 | 未整改、整改中、已提交、审核中、已退回等尚未完成销号的问题 |
| 超期问题 | 已超过整改期限但尚未完成销号的问题 |
| 案例沉淀 | 已进入案例库或已审核通过的专项整改成果数量 |

专项监督卡片点击后打开对应抽屉，抽屉以专项问题台账、区划整改状态、专项主题汇总、超期问题明细和案例沉淀明细承接，不展示日常监督规则触发、预警疑点等口径。

选择具体主题后，顶部卡片切换为：

| 卡片 | 展示含义 |
|---|---|
| 平均分 | 同一主题、同一评价体系下各区划平均得分 |
| 低分区划数 | 当前主题下低于阈值或命中关注条件的区划数量 |
| 预警疑点数量 | 当前主题下规则发现线索数量 |
| 确认问题数量 | 当前主题下确认问题数量 |
| 确认问题金额 | 当前主题下确认问题金额 |
| 案例沉淀数 | 当前主题下已形成正式案例沉淀的数量 |

四种筛选状态下，第 6 张卡片均统一为“案例沉淀数”：

| 当前状态 | 案例沉淀数统计范围 |
|---|---|
| 多主题 × 多区划 | 当前全辖、全部日常主题下的案例 |
| 多主题 × 单区划 | 当前区划、全部日常主题下的案例 |
| 单主题 × 多区划 | 当前主题、全辖多区划下的案例 |
| 单主题 × 单区划 | 当前主题、当前区划下的案例 |

案例沉淀数纳入口径：

| 纳入 | 说明 |
|---|---|
| 已入库案例 | 已通过审核并进入案例库 |
| 已发布典型案例 | 已标记典型或已发布 |
| 已审核待发布案例 | 当前原型先纳入统计，后续可按业务确认调整 |

案例沉淀数不纳入口径：

| 不纳入 | 原因 |
|---|---|
| 草稿案例 | 尚未形成正式成果 |
| 审核退回案例 | 质量未确认 |
| 普通问题明细 | 问题不等于案例 |
| 未核实疑点 | 疑点不是案例结果 |
| 仅保存未提交案例 | 不具备成果属性 |

点击“案例沉淀数”后打开“案例沉淀明细”抽屉。

抽屉视觉参考主页面的无硬边框风格：顶部不显示“指标解释”这类通用标签，收起操作使用图标按钮；当前统计口径仅作为弱提示展示，避免和主页面口径重复抢占注意力。主值区采用横向布局，左侧展示主数值和短说明，右侧放典型案例数、涉及主题数、涉及区划 / 单位数等关键摘要。暂不展示计算口径、数据来源、分子、分母等技术说明块；摘要、筛选和明细表通过浅底色、弱阴影、圆角和留白形成分区，不使用重边框卡片，也不能完全取消分界感。

## 6. 左侧板块：需关注区划

该板块用于识别当前行政区划范围内哪些本级或下级区划需要重点关注。

未选择具体主题时展示：

- 区划名称；
- 关注状态；
- 低分主题数 / 占比；
- 预警疑点数；
- 确认问题数量；
- 确认问题金额；
- 主要关注原因。

选择具体主题后展示：

- 区划名称；
- 当前主题得分；
- 低分指标 / 扣分指标；
- 预警疑点数；
- 确认问题数量；
- 确认问题金额；
- 主要扣分原因。

排序规则：

1. 关注状态；
2. 确认问题金额；
3. 确认问题数量；
4. 低分主题数 / 占比或主题得分；
5. 预警疑点数。

点击市州区划后进入该市州全辖分析；点击省本级或区县时跳转到“本级监督分析”。

专项监督下，左侧仍使用“需关注区划”板块，但字段切换为专项整改口径：

- 区划名称；
- 关注状态；
- 问题总数；
- 问题金额；
- 未销号问题；
- 超期问题；
- 退回问题；
- 督办问题；
- 案例沉淀；
- 主要专项主题和关注原因。

专项监督排序优先看超期问题、未销号问题、问题金额、退回问题、督办问题和问题总数，不展示日常监督的低分主题、预警疑点和确认问题字段。

## 7. 中间板块：区划关注分布

该板块不是纯地图，而是“本级卡片 + 下级区划地图 + 维度页签”。维度页签复用原全辖分析的右上角分段按钮样式，放在板块标题右侧，不压到地图内容区。

默认省级全辖时：

- 本级卡片展示湖南省本级关注情况；
- 地图展示各市州关注分布；
- 省本级和市州同级参与关注判断。

市级全辖时：

- 本级卡片展示市本级关注情况；
- 地图展示各区县关注分布。

地图页签：

| 页签 | 作用 |
|---|---|
| 综合表现 | 默认视图，展示综合表现分和总体关注程度 |
| 评分表现 | 看多主题评分表现 |

## 8. 右侧板块

默认多主题 × 多区划状态下，右侧为“需关注主题”，用于识别当前行政区划、日常监督、全部日常主题口径下哪些监督主题需要重点关注。

左侧“需关注区划”和右侧“需关注主题”的辅助说明放在标题同行右上角，以小字号、低对比度展示，不占用列表首行空间。

主题侧不展示“综合表现”字段。主题列表优先展示平均分和中位分，用评分分布、低分区划和问题证据辅助判断关注程度。

- 主题名称；
- 关注状态；
- 平均分；
- 中位分；
- 低分区划数 / 占比；
- 预警疑点数；

- 确认问题金额；
- 案例沉淀数；
