# 湖南问题库演示原型规格

## 1. 页面定位

本原型用于湖南财会监督一期“问题入口 + 结果归集”演示，目标是先让不同来源的问题进得来、沉得下、查得到，再考虑线上分发和整改流转。

本期只建设“问题归集登记”和“问题台账管理”两个菜单。动态表头通过预置来源模板直接演示，暂不建设表单配置后台；不接入真实接口、数据库、权限或线上办理流程。

## 2. 功能范围

### 2.1 问题归集登记

- 支持巡视、审计、专项检查、日常监督、外部移交和其他来源的问题统一归集。
- 支持批量导入和人工录入。
- 选择问题来源后自动匹配预置模板，并在列表、导入预览和信息确认页动态展示来源扩展字段。
- 列表状态包括待确认、待补充、已入库、不入库和全部。
- 批量导入页展示来源模板、文件选择、数据预览、字段映射结果以及缺失、格式和重复提示。
- 信息确认页同时展示原始导入数据、系统通用字段和来源扩展字段，支持补充信息、暂存、不入库和确认入库。
- 正式入库后进入问题台账；不建设问题分发、任务下发或审批流程。

### 2.2 问题台账管理

- 统一查询已经入库的问题存量数据。
- 支持按问题来源、年度、问题类型、责任单位和整改状态筛选。
- “全部来源”展示通用字段；切换具体来源后追加该来源的动态字段。
- 支持查询方案、列设置和导出演示。
- 问题详情展示通用信息、来源扩展信息、原始材料、整改结果和更新记录。
- 支持对线下已经完成的整改结果进行回录，包括整改情况、整改措施、完成时间、整改材料、销号结论、销号时间和销号材料。
- 整改回录只形成历史台账，不表达线上办理、审核或审批过程。

## 3. 信息架构

```text
湖南问题库
├── 公共 TopBar
├── 问题库功能菜单
│   ├── 问题归集登记
│   └── 问题台账管理
└── 当前模块展示区
    ├── 归集列表 → 批量导入预览 / 人工录入 / 信息确认
    └── 台账列表 → 问题详情 → 整改结果回录
```

表单配置作为后续扩展模块预留，不在本期菜单中展示。

## 4. 预置动态模板

| 问题来源 | 通用字段之外的演示字段 |
| --- | --- |
| 巡视移交 | 巡视批次、巡视组、移交日期 |
| 审计移交 | 审计项目、审计文号、审计年度 |
| 专项检查 | 专项名称、检查项目、检查期间 |
| 日常监督 | 监督主题、发现渠道、监控规则 |
| 外部移交 | 移交单位、移交文号、移交日期 |

所有模板都共享问题标题、问题来源、责任单位、问题类型、问题事实、涉及金额、发现时间和附件等通用字段。

## 5. 关键页面

### 5.1 问题归集列表

- 顶部状态页签。
- 左侧来源目录，右侧标准工具栏和动态字段表格。
- 主要操作为批量导入、人工录入、批量入库和导出。
- 行级主操作为“确认信息”，次要操作为查看来源材料。

### 5.2 批量导入预览

- 64px 全页面操作页头。
- 顶部选择问题来源、对应模板和导入文件。
- 下方显示字段映射摘要和导入数据预览。
- 异常直接定位到数据行，支持返回调整、仅导入可用数据和进入信息确认。

### 5.3 信息确认 / 人工录入

- 左侧展示来源材料或导入原始数据，右侧展示通用字段和来源扩展字段。
- 字段按“问题基础信息、来源扩展信息、材料附件”分组。
- 人工录入和导入确认复用同一表单结构；人工录入不显示原始导入值。

### 5.4 问题台账列表

- 使用连续白色业务面板和标准表格，不做统计卡片。
- 具体来源切换后追加来源扩展字段，列头同步变化。
- 行级操作保留“查看详情”和“整改回录”。

### 5.5 问题详情与整改回录

- 详情页通过页签查看问题信息、来源信息、整改结果和更新记录。
- 整改回录使用全页面表单，突出最终结果、佐证材料和销号信息。
- 不展示分发路径、整改进度时间轴、督办、审核、退回或线上销号审批。

## 6. 数据与交互

- 数据全部为页面内本地 mock 数据。
- 左侧功能菜单支持展开和收起，并通过 `feature` 查询参数记录当前模块。
- 来源选择会切换列表表头和表单扩展字段。
- 导入、保存、入库、回录、销号和导出只提供演示反馈。
- Axure 变量暴露当前 `feature_key` 和 `feature_name`。

## 7. 布局与视觉

- 复用公共 `TopBar`、案例库左侧功能菜单、标准页签、工具栏、表格、分页、表单页头和表单控件。
- 页面采用“TopBar → 问题库功能菜单 → 业务区”的结构；业务区有来源目录时继续为“来源目录 → 列表”。
- 业务面板和业务卡片统一 `8px` 圆角，控件使用 `4px` 圆角。
- 遵循无边框优先，通过白色工作面、浅底分组、文字层级和必要分隔组织信息。
- 动态字段使用轻量“当前模板 / 动态字段”提示，不额外增加大标题或说明卡片。

## 8. 暂不处理

- 表单模板配置后台及模板版本管理。
- 真实 Excel 解析、字段映射和数据校验。
- 问题自动去重、智能分类或标签算法。
- 问题分发、转办、整改任务下发、进度填报、督办和逾期提醒。
- 整改审核、退回、线上销号审批和统计看板。
