# UFSP Sky 主题设计规范

## 1. 主题定位

`ufsp-sky` 是财会监督 V2.0 原型的公共浅色政务主题，用于首页、工作台、全局分析、评价图谱和功能列表等主业务页面。

## 2. 页面背景

- 全局页面背景使用 `--ufsp-global-page-background`。
- 背景结构为左上浅蓝径向光晕、右上青蓝径向光晕和纵向浅蓝渐变，来源于全局总览页面验证后的视觉方向。
- 顶层页面容器由主题统一覆盖，页面内业务卡片继续使用白底、轻阴影和弱层级。

## 3. 基础色

- 页面底色兜底：`#F3F7FF`
- 前景文字：`#1E293B`
- 卡片背景：`#FFFFFF`
- 主色：`#1E40AF`
- 强调色：`#3EACEF`

## 4. 使用约束

- 主业务页面应优先导入 `src/themes/ufsp-sky/globals.css`，由主题提供统一背景。
- 不在各页面重复复制背景渐变，避免后续页面之间出现色值漂移。
- 背景渐变只承担页面环境氛围，不作为业务状态色；风险、预警、成功等状态仍使用各页面现有语义色。
